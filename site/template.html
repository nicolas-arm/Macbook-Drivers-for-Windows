1

Find your model identifier

Every Mac has a short code like MacBookPro14,3. It's different from the marketing name, “MacBook Pro (15‑inch, 2017)”, and only the code tells you exactly which drivers fit. Pick whichever way is easiest.

macOS · no typing

System Information

  1. Hold ⌥ Option and click the Apple menu.
  2. Click System Information…
  3. Under Hardware, read Model Identifier.
Model Name:
MacBook Pro
Model Identifier:
MacBookPro14,3
Processor Name:
Quad-Core Intel Core i7
macOS · Terminal

One command

  1. Open Terminal (Spotlight: ⌘ Space, type “Terminal”).
  2. Paste this and press Return:
sysctl -n hw.model

It prints the identifier, for example MacBookPro14,3.

Already in Windows

PowerShell

  1. Right-click Start and open Terminal or PowerShell.
  2. Paste this and press Enter:
(Get-CimInstance Win32_ComputerSystem).Model

Windows reads the same code from the Mac's firmware.

Identifiers like Mac14,2, MacBookAir10,1 or MacBookPro17,1 mean Apple silicon (M1 or newer). Those Macs can't run Boot Camp, so Apple never made Windows drivers for them. MDfW covers Intel Macs from 2006 to 2020.

Enter it and download

Type the identifier into the driver lookup at the top, exactly as shown, comma included. Upper or lower case doesn't matter.

Type the code

The lookup matches it against every Boot Camp package Apple has published, as soon as you type.

Press Download drivers

Your browser saves BootCampESD.pkg from Apple, usually to your Downloads folder.

Keep it on a USB stick

If Windows is already installed, put the file somewhere you can reach it from there.

If several packages list your model, MDfW picks the newest one. That's the same choice Boot Camp Assistant makes.

3

Get Setup.exe out of the package

The .pkg is a macOS installer, so Windows can't open it directly. The drivers sit three layers deep. Unpack them on whichever computer you have, then run Setup.exe from Windows.

BootCampESD.pkg └─ Payload └─ Library/Application Support/BootCamp/WindowsSupport.dmg ├─ $WinPEDriver$/ └─ BootCamp/ ├─ Drivers/ └─ Setup.exe ← run this in Windows
  1. Install 7-Zip

    It's free and opens Apple's package formats. Get it at 7-zip.org.

  2. Unpack the package

    Right-click BootCampESD.pkg › 7-Zip › Extract to "BootCampESD\".

  3. Unpack the payload

    In that folder, extract Payload the same way. If you then see a file named Payload~, extract that too. You end up with Library\Application Support\BootCamp\WindowsSupport.dmg.

  4. Unpack the disk image

    Extract WindowsSupport.dmg. You get the BootCamp and $WinPEDriver$ folders.

  5. Install

    Open BootCamp, right-click Setup.exe › Run as administrator, and restart when it's done.

Prefer the command line? With 7-Zip installed, this does steps 2–4 in one go from the folder holding the package:

# PowerShell
$7z = "$env:ProgramFiles\7-Zip\7z.exe"
& $7z x -y -obc BootCampESD.pkg
& $7z x -y -obc bc\Payload
if (Test-Path bc\Payload~) { & $7z x -y -obc bc\Payload~ }
& $7z x -y -oWindowsSupport (Get-ChildItem bc -Recurse -Filter WindowsSupport.dmg).FullName
start WindowsSupport\BootCamp
  1. Open Terminal and go to your Downloads 
    cd ~/Downloads
  2. Unpack the package and its payload

    macOS includes everything needed.

    pkgutil --expand BootCampESD.pkg bc
mkdir bc_files && tar -xzf bc/Payload -C bc_files
open "bc_files/Library/Application Support/BootCamp/WindowsSupport.dmg"
  3. Copy the drivers to a USB stick

    A WindowsSupport disk opens in Finder. Copy its BootCamp and $WinPEDriver$ folders to a USB stick formatted as ExFAT or MS-DOS (FAT). Windows can't read Mac-formatted drives.

  4. Install in Windows

    Plug the stick in, open BootCamp, right-click Setup.exe › Run as administrator, and restart.

This one script unpacks the package on any system. On a Mac it uses built-in tools. On Windows or Linux it uses 7-Zip. Save it as mdfw_extract.py next to the package, then run:

python3 mdfw_extract.py BootCampESD.pkg WindowsSupport

It prints the path to Setup.exe when it's done. Python 3.8 or newer, no extra packages.
